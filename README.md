# SonSimsBax
SonSimsBax finds your Mods folder, lists every package and script inside it, and lets you switch mods off without deleting a single file. No more mystery crashes from a mod you forgot you had.

Windows, as a standalone .exe

Requires Python installed once, only to build the program. The result runs on its own afterward.

    Install Python and check "Add python.exe to PATH".
    Put sonsimsbax.py and build.bat in one folder.
    Double-click build.bat.
    Open dist\SonSimsBax.exe — that's it.
